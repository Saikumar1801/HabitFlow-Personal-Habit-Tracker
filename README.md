# HabitFlow - Personal Habit Tracker

![HabitFlow Screenshot](screenshot.png)

HabitFlow is a modern, feature-rich habit tracking application designed to help you build and maintain positive habits. With a clean interface, powerful analytics, and gamification elements, HabitFlow makes habit formation engaging and rewarding.

## Features

### Core Features
- **Habit Management**
  - Create, edit, and track daily habits
  - Mark habits as complete with one click
  - Set priorities to organize your habits
  - Drag-and-drop reordering of habits
  - Detailed habit history tracking

- **Progress Tracking**
  - Daily streak counter
  - Completion percentage
  - Habit history visualization
  - Category-based organization

- **Time Management**
  - Time blocking for habit scheduling
  - Time estimates for each habit
  - Best time of day suggestions (morning/afternoon/evening)

### Gamification
- **XP System**
  - Earn XP for completing habits
  - Level up as you progress
  - Visual progress indicators

- **Achievements**
  - Unlock badges for milestones
  - Track progress toward goals
  - Achievement notifications

### Analytics
- **Visual Reports**
  - Weekly completion charts
  - Category distribution pie charts
  - Streak performance over time
  - Habit completion history

### Reminders & Notifications
- **Custom Reminders**
  - Set daily reminder times
  - Toggle reminders on/off
  - Notification system

### Smart Features
- **AI Suggestions**
  - Get personalized habit recommendations
  - Time-based suggestions
  - Improvement tips for struggling habits

### Utility Features
- **Data Export**
  - Export your data as JSON or CSV
  - Full backup capability

- **Theme Support**
  - Light and dark mode
  - Automatic theme switching

## Technologies Used

### Frontend
- **React** - JavaScript library for building user interfaces
- **Next.js** - React framework for server-side rendering
- **TypeScript** - Typed JavaScript superset
- **Tailwind CSS** - Utility-first CSS framework
- **Framer Motion** - Animation library for React
- **Recharts** - Charting library for React
- **Lucide React** - Beautiful, consistent icon set
- **FileSaver.js** - Client-side file saving

### Backend (Client-side)
- **LocalStorage** - Client-side data persistence
- **Date-fns** - Date utility library

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/habitflow.git
   cd habitflow
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   ```

3. Run the development server:
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Usage

1. **Add Habits**: Click the "Add Habit" button to create new habits with details like category, priority, and XP value.
2. **Track Progress**: Mark habits as complete each day to build streaks and earn XP.
3. **Schedule Time**: Use time blocking to allocate specific times for your habits.
4. **Set Reminders**: Configure reminders to never miss a habit.
5. **View Analytics**: Check the analytics tab to see your progress over time.
6. **Export Data**: Backup your habit data using the export feature.
